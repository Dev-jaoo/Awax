# Awax — Landing Page

Projeto de desenvolvimento de uma landing page para uma agência criativa fictícia, chamada **Awax**, com foco na apresentação de serviços, projetos, equipe e informações de contato.

O projeto foi desenvolvido em parceria com o professor **Bonieky Lacerda**, durante as aulas do curso **B7Web**, com o objetivo de praticar e aprimorar os conhecimentos em desenvolvimento Front-End.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts

## 📌 Funcionalidades e seções

A página apresenta diferentes seções que simulam o site institucional de uma agência:

- **Home:** banner principal com chamada para ação.
- **About Us:** apresentação da agência.
- **Services:** exibição dos serviços oferecidos.
- **Our Projects:** galeria de projetos e imagens.
- **Our Team:** apresentação dos integrantes da equipe.
- **Happy Clients:** seção de depoimentos.
- **Price:** tabela de planos e preços.
- **Premium:** apresentação de recursos adicionais.
- **Some Facts:** indicadores e estatísticas.
- **Contact Us:** formulário de contato.
- **Footer:** redes sociais e formulário de inscrição.

## 📱 Responsividade

O projeto utiliza Media Queries para adaptar o layout a diferentes tamanhos de tela, incluindo dispositivos desktop, tablets e smartphones.

## 🎯 Objetivo do projeto

Praticar conceitos fundamentais de HTML e CSS, especialmente:

- Estruturação semântica com HTML.
- Organização e estilização com CSS.
- Construção de layouts utilizando Flexbox.
- Posicionamento e alinhamento de elementos.
- Criação de layouts responsivos com Media Queries.
- Organização de código e utilização de classes CSS.
